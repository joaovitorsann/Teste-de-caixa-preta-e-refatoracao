# Calculadora em Java

## 1. Descrição do Projeto

Este projeto consiste no desenvolvimento de uma calculadora utilizando a linguagem Java. A aplicação realiza operações matemáticas básicas entre dois números inteiros, apresentando o resultado ou uma mensagem de erro quando necessário.

O código foi organizado utilizando métodos para separar as responsabilidades e facilitar a manutenção.

## 2. Objetivo da Atividade

O objetivo desta atividade é aplicar conceitos de programação orientada a objetos, refatoração de código, documentação e testes automatizados.

Também busca desenvolver a capacidade de organizar um projeto Java e utilizar ferramentas como JUnit e JavaDoc.

## 3. Tecnologias Utilizadas

- Java: linguagem utilizada no desenvolvimento.
- JUnit 5: biblioteca utilizada para realizar os testes unitários.
- JavaDoc: ferramenta utilizada para gerar a documentação do código.
- GitHub: plataforma utilizada para armazenar e compartilhar o projeto.

## 4. Operações Disponíveis

A calculadora possui quatro operações matemáticas:

| Operação | Símbolo | Descrição |
|---|---|---|
| Adição | + | Soma dois números inteiros. |
| Subtração | - | Subtrai o segundo número do primeiro. |
| Multiplicação | * | Multiplica dois números inteiros. |
| Divisão | / | Divide o primeiro número pelo segundo. |

O programa também possui tratamento para situações inválidas, como operadores não reconhecidos e tentativas de divisão por zero.

Observação: a divisão utiliza números inteiros, portanto não apresenta casas decimais.

## 5. Testes Unitários

Foram desenvolvidos testes utilizando JUnit 5 para verificar o funcionamento das operações e o tratamento de erros.

Os cenários testados foram:

- Adição.
- Subtração.
- Multiplicação.
- Divisão.
- Divisão por zero.
- Operador inválido.
